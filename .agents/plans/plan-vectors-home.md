# Plan: Algorithm test vectors home (bindings-only)

## Context

Per [BIPs PR #2202](https://github.com/bitcoin/bips/pull/2202) and [cryptoquick’s comment](https://github.com/bitcoin/bips/pull/2202#issuecomment-4955875755): Rust/JS reference code should live in **libbitcoinpqc-bindings** as integration/e2e tests, not in the BIPs repo. BIPs keeps the minimal Python P2MR construction reference.

This plan covers **tapscript signature algorithm golden vectors** (BIP-340 row 0, ML-DSA-44, SLH-DSA-SHA2-128s) — what `libbitcoinpqc` implements. That is separate from **BIP-360 P2MR script-tree vectors** in notmike-5’s PR.

**Constraints**

- Bindings repo only; **no libbitcoinpqc feature work** (upstream is done for this effort).
- Canonical JSON stays in-repo; generated artifacts per language are committed and CI-gated.
- `sync-golden-vectors.py` remains the single generator (already fans out to Rust, Python, Node, WASM, C headers).

**Non-goals**

- libbitcoinpqc submodule pointer bumps or C library API changes.
- BIP-360 P2MR construction vectors or Python ref impl (stays in BIPs).
- Changing fixture cryptographic values (unless a deliberate vector update is requested later).

**Assumption**

- `libbitcoinpqc/tests/vectors/*.h` stays the **sync output target** for C ctest (generated bytes only). Reorganizing bindings layout does not require editing upstream C source if fixture JSON is unchanged.

## Approach

Give algorithm vectors a single documented tree under `tests/vectors/`, move canonical JSON there, colocate all **generated** per-language artifacts under language subdirs, rewire binding tests to import from that tree, polish non-Rust test suites toward Rust parity, then verify with `just ci` and align package versions for manual publish.

```
tests/vectors/
  README.md              # purpose, regen, BIPs link, duplicate-with-BIPs note
  fixtures/              # canonical JSON (moved from tests/fixtures/)
    secp256k1_bip340_row0.json
    ml_dsa_44_golden.json
    slh_dsa_sha2_golden_vectors.json
  rust/                  # *.rs (generated)
  python/                # *_golden_vectors.py (generated)
  nodejs/                # *.js + *.d.ts (generated)
  wasm/                  # *.js (generated)
```

`sync-golden-vectors.py` writes:

- `tests/vectors/{rust,python,nodejs,wasm}/`
- `libbitcoinpqc/tests/vectors/*.h` (unchanged destination; submodule gets regenerated headers only)

Remove scattered copies from `python/tests/`, `nodejs/tests/`, `wasm/test/`, and flat `tests/vectors/*.rs`.

**Not relocating C headers into bindings** — C tests keep including from the submodule path; avoids CMake/build changes upstream.

## Steps

1. **Create `tests/vectors/README.md`** — document fixtures → sync → per-language outputs; note intentional duplication vs BIPs (algorithm vs P2MR); link for notmike-5 to drop Rust/JS from BIPs PR.

2. **Move fixtures** — `tests/fixtures/*.json` → `tests/vectors/fixtures/`; delete empty `tests/fixtures/`.

3. **Update `sync-golden-vectors.py`** — `FIXTURES = tests/vectors/fixtures`; output to `rust/`, `python/`, `nodejs/`, `wasm/`; update generated file headers; C headers still → `libbitcoinpqc/tests/vectors/`.

4. **Run `make sync-vectors`** — regenerate all artifacts; confirm submodule `.h` diff is empty if JSON unchanged.

5. **Rewire test imports** — Rust `#[path]`, Python `sys.path` or relative import, Node/WASM `require`/`import` from `../../tests/vectors/...`.

6. **Delete old generated files** — `python/tests/*_golden_vectors.py`, `nodejs/tests/*_golden_vectors.*`, `wasm/test/*_golden_vectors.js`, flat `tests/vectors/*.rs`.

7. **Polish binding tests** (best effort vs Rust):
   - Python: explicit golden tests for all three algos; tamper-on-verify for ML/SLH (match Node); consistent test names.
   - Node: already strong; ensure imports only from vectors tree.
   - WASM: same golden coverage; reduce duplicated console-test boilerplate if easy without scope creep.

8. **Update CI gates** — `just vectors-in-sync`, `flake.nix` vectors check, Makefile help text; single path list `tests/vectors`.

9. **Version + publish prep** — bump to **`0.4.1`** on Cargo/npm/PyPI manifests (pre-polish 0.4.0 Rust crate from last week); add README publish pointers; run `just ci`.

10. **Optional README blurb for BIPs** — suggested link text notmike-5 can paste: algorithm e2e vectors + Rust/Node/WASM tests live at bindings repo `tests/vectors/`.

Depends: 3→4→5→6 sequential; 7–9 parallel after 6.

## Risks

- **Jest/Node path resolution** — use repo-relative imports; verify `npm test` from `nodejs/`.
- **Python import path** — add `tests/vectors/python` to path in `test_bitcoinpqc.py` only (not package install).
- **Accidental submodule commit** — if JSON unchanged, `.h` should be identical; gate catches drift.

## Verification

```bash
make sync-vectors
just vectors-in-sync
just ci
```

Manual: skim `tests/vectors/README.md`; confirm no golden files left under old paths.
