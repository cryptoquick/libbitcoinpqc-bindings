# BIP-360 P2MR construction vectors

Living test vectors for **Pay-to-Merkle-Root (P2MR)** script-tree construction
and control blocks (BIP-360). Separate from algorithm golden vectors
(secp256k1 / ML-DSA-44 / SLH-DSA-SHA2) under `tests/vectors/fixtures/`.

## Provenance

Copied from [bitcoin/bips#2202](https://github.com/bitcoin/bips/pull/2202)
(`notmike-5` et al.) before ref-impl removal from the BIPs PR.

| Field | Value |
|-------|--------|
| PR | https://github.com/bitcoin/bips/pull/2202 |
| Commit | `3e3e4347e2777abdb0cc131b7f8b4f5a37ec49ba` |
| Source paths | `bip-0360/ref-impl/common/tests/data/*.json` |

## Fixtures

| File | Role |
|------|------|
| `fixtures/p2mr_construction.json` | Classic P2MR construction vectors |
| `fixtures/p2mr_pqc_construction.json` | P2MR / PQC construction vectors |

Languages **must** load these files from this directory (do not fork copies
into each binding tree).

## Consumers

- Python: `python/p2mr/` + `python/tests/test_p2mr_construction.py`
- Rust: `tests/p2mr_construction.rs`
- Node: `nodejs/tests/p2mr_construction.test.ts`
- Full archival snapshot: `examples/bip360-workshop/`

### Which fixture is the multi-language bar?

| Fixture | CI role |
|---------|---------|
| `p2mr_construction.json` | **Required** — pure construction ref (Python / hermetic Rust / Node) |
| `p2mr_pqc_construction.json` | **Preserved** living data for rust-bitcoin / workshop stacks; presence checked in CI, full equality not required of the pure-Python ref |

## Updating

When BIP-360 construction semantics or official vectors change, update the
JSON here and re-run language e2e. These are **not** generated by
`scripts/sync-golden-vectors.py`.
